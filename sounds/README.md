# 機長廣播提示音效

這個資料夾用於存放機長廣播前的提示音效文件。

## 音效文件

請將音效文件命名為 `airplane-chime.mp3` 並放在此資料夾中。

## 推薦音效資源

### 免費音效網站（建議下載飛機機艙提示音/叮咚聲）：

1. **Pikbest** (https://zh.pikbest.com/free-sound-effects/)
   - 搜索關鍵詞：飛機廣播、機艙提示音、airplane announcement
   - 提供多種風格的音效，部分免費

2. **愛給網** (https://www.aigei.com/sound/)
   - 搜索關鍵詞：飛機廣播、機艙提示音
   - 提供免費下載的音效素材

3. **Freesound.org** (https://freesound.org/)
   - 搜索關鍵詞：airplane chime, cabin announcement, ding dong
   - 完全免費，需註冊
   - 推薦搜索：`airplane cabin chime` 或 `aircraft announcement sound`

4. **Zapsplat** (https://www.zapsplat.com/)
   - 搜索關鍵詞：airplane chime, aircraft announcement
   - 免費註冊後可下載

5. **YouTube Audio Library** (https://studio.youtube.com/channel/UC.../music)
   - 搜索：notification, chime, ding
   - 完全免費使用

## 音效要求

- **格式**：MP3 或 WAV
- **長度**：0.5-2 秒（簡短的提示音）
- **音量**：適中，不要太響
- **風格**：類似飛機機艙內的「叮咚」提示音

## 使用方式

音效會在機長廣播開始前自動播放，增加沉浸感。

如果音效文件不存在或載入失敗，系統會自動跳過音效播放，不影響廣播功能。
